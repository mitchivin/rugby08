# rugby08

Rugby 08 in your browser.

**[Play rugby08](https://mitchivin.github.io/rugby08/)**

Open the link to play. Game files download automatically; there is no folder picker or local installation step. Chrome or Edge on a computer is recommended.

This public repository contains project information and Pages publishing configuration only. Product source and the prepared engine build are maintained in a private repository. Source, WebAssembly, compiled releases and game files are not committed to this public repository. Pages receives only a deployment artifact. Larger game assets are delivered from Cloudflare storage.

Online rooms are being connected separately. The browser game runs locally on your device; closing the page stops it.
